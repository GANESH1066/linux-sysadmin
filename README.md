# Linux System Administration Portfolio

This repository documents my hands-on journey learning Linux System Administration, mapped directly to real-world job requirements.

*   **[02-users-permissions](./02-users-permissions/)**: User creation, groups, file permissions, and security.
*   **[03-monitoring](./03-monitoring/)**: Checking disk space, memory, CPU, and system health.
*   **[04-updates](./04-updates/)**: Package management, applying security patches, and rebooting safely.
*   **[05-backups](./05-backups/)**: Backup strategies, archiving files, and restoring data.
*   **[06-networking](./06-networking/)**: IP addressing, DNS, ping, and port troubleshooting.
*   **[07-assets](./07-assets/)**: Basic IT asset tracking and licensing.
