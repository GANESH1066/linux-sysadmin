# Linux System Administration Portfolio

This repository documents my hands-on Linux System Administration skills, mapped directly to real-world job requirements (L1/L2 SysAdmin). 

## 📂 Course Modules

*   **[01-navigation](./01-navigation/)**: File system structure, navigation, and file operations.
*   **[02-users-permissions](./02-users-permissions/)**: User creation, groups, `chmod`, `chown`, and security auditing.
*   **[03-monitoring](./03-monitoring/)**: Checking disk space (`df`), memory (`free`), CPU (`top`), and system load (`uptime`).
*   **[04-updates](./04-updates/)**: Package management, applying security patches (`dnf`), and rollback history.
*   **[05-backups](./05-backups/)**: Backup strategies with `tar` and `rsync`, automated via `cron`.
*   **[06-networking](./06-networking/)**: IP addressing (`ip a`), connectivity (`ping`), DNS (`dig`), and port troubleshooting (`ss`).
*   **[07-assets](./07-assets/)**: Hardware inventory and OS auditing (`lsblk`, `hostnamectl`).
