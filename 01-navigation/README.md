# Module 1: Navigation & File Management

## Navigation Commands
- `pwd`: Print Working Directory (shows exactly where you are).
- `ls`: List files and folders in the current directory.
- `cd <folder>`: Change directory (enter a folder).
- `cd ..`: Go up one level.
- `cd /`: Go to the absolute root of the system.
- `cd ~`: Go to the current user's home directory.

## File Operations
- `touch <file>`: Create a new, empty file.
- `mkdir <folder>`: Create a new directory.
- `cp <source> <destination>`: Copy a file.
- `mv <source> <destination>`: Move or rename a file.
- `rm <file>`: Delete a file.
- `rm -r <folder>`: Delete a folder and everything inside it.
